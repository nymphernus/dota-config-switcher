# DotaConfigSwitcher

Графическое приложение на Python (PySide6) для переключения конфигов Dota 2 между разными наборами настроек.

Приложение копирует содержимое папки `<config_name>\570` в `<STEAM_PATH>\userdata\<STEAM_ID>\570` (и обратно при сохранении).

## Возможности

- Автоопределение пути Steam (стандартный путь + реестр Windows) и ручной выбор папки.
- Сканирование аккаунтов в `<STEAM_PATH>\userdata\` (числовые Steam AccountID), проверка наличия папки `570` (Dota 2).
- Получение никнеймов и аватарок из **локальных файлов Steam** (без интернета и без Steam Web API).
- Локальный кэш аватарок в папке `cache/avatars/` (обновляется, если исходник в `avatarcache` новее).
- Список конфигов (папки с подпапкой `570`) с датой изменения и размером.
- Применение конфига (полная замена содержимого `userdata\<id>\570`), сохранение текущего, удаление, переименование, открытие папки в проводнике.
- Фоновые операции (копирование, чтение профилей) с прогрессом/блокировкой UI.
- Локальные настройки в `%APPDATA%\DotaConfigSwitcher\settings.json`, лог в `app.log`.
- Системный трей: быстрое применение конфигов к избранному профилю.
- Удобный темный интерфейс с кастомными диалогами (без нативных окон Windows, чтобы избежать проблем с кодировкой).

## Как это работает (локальные источники профилей)

Приложение не выполняет сетевых запросов для получения профилей. Никнеймы и аватарки читаются с диска:

- **`<STEAM_PATH>\config\loginusers.vdf`** — основной источник никнейма.
  - Ключи аккаунтов в нём — **SteamID64**; для сопоставления с папками `userdata` используется `AccountID = SteamID64 - 76561197960265728`.
  - Извлекается `PersonaName`, при отсутствии — fallback на `AccountName`.
- **`<STEAM_PATH>\userdata\<AccountID>\config\localconfig.vdf`** — fallback-источник никнейма.
- **`<STEAM_PATH>\config\avatarcache`** — источник аватарок (best-effort). Поиск выполняется эвристически, найденные изображения кэшируются локально.

**Оговорка:** загрузка аватарок работает по принципу *best-effort* и может не найти изображение для некоторых аккаунтов. В этом случае показывается встроенная заглушка-аватарка.

## Требования

- Windows 10/11
- Python 3.10+
- Установленный Steam (для работы с `userdata` и локальными файлами профилей)

## Установка и запуск (из исходников)

1. Создайте виртуальное окружение:
   ```powershell
   python -m venv .venv
   ```
2. Активируйте venv (Windows PowerShell):
   ```powershell
   .venv\Scripts\Activate.ps1
   ```
3. Установите зависимости:
   ```powershell
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```powershell
   python main.py
   ```

## Сборка EXE (PyInstaller)

Сборку выполнять внутри активированного `.venv`.

### Быстрый способ (скрипт)

```powershell
.\build.ps1
```

### Вручную

```powershell
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name "DotaConfigSwitcher" --icon="icon.ico" main.py
```

Готовый файл: `dist\DotaConfigSwitcher.exe`.

## Настройка и использование

- **Путь к Steam:** определяется автоматически, при необходимости задаётся вручную в настройках.
- **Steam аккаунт:** выбирается в верхнем выпадающем списке. Избранный профиль закрепляется первым.
- **Папка конфигов:** по умолчанию — в `%APPDATA%\DotaConfigSwitcher\configs\`. Каждый конфиг — папка, содержащая подпапку `570`.
- **Обновить профили:** кнопка в интерфейсе перечитывает `loginusers.vdf` и `avatarcache` без перезапуска приложения.

Перед применением/сохранением рекомендуется закрыть Steam и Dota 2, иначе возможны ошибки доступа к файлам.

## Структура проекта

- `main.py` — точка входа, логирование, запуск GUI
- `settings.py` — загрузка/сохранение `settings.json`, пути к кэшу/логу
- `steam.py` — поиск Steam, перечисление аккаунтов, парсинг VDF и чтение профилей/аватарок
- `configs.py` — список/валидация/копирование/удаление/переименование конфигов
- `ui/` — интерфейс (`main_window.py`, `settings_dialog.py`, `widgets.py`, фоновые задачи)
- `build.ps1` — скрипт сборки EXE (PyInstaller)
- `icon.ico` — иконка приложения

## Хранение данных

- `settings.json` — настройки приложения
- `cache/avatars/` — локальный кэш аватарок
- `app.log` — журнал работы приложения

Эти файлы/папки создаются в `%APPDATA%\DotaConfigSwitcher`.
