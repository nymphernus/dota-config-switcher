# Dota 2 Config Switcher

Графическое приложение на Python (PySide6) для переключения конфигов Dota 2 между разными наборами настроек.

Приложение копирует содержимое папки `<config_name>\570` в `<STEAM_PATH>\userdata\<STEAM_ID>\570` (и обратно при сохранении).

## Возможности

- Автоопределение пути Steam (стандартный путь + реестр Windows) и ручной выбор папки.
- Сканирование аккаунтов в `<STEAM_PATH>\userdata\` (числовые Steam AccountID), проверка наличия папки `570` (Dota 2).
- Получение никнеймов и аватарок из **локальных файлов Steam** (без интернета и без Steam Web API ключа).
- Локальный кэш аватарок в папке `cache/avatars/` (обновляется, если исходник в `avatarcache` новее).
- Список конфигов (папки с подпапкой `570`) с датой изменения и размером.
- Применение конфига (полная замена содержимого `userdata\<id>\570`), сохранение текущего, удаление, открытие папки в проводнике.
- Фоновые операции (копирование, чтение профилей) с прогрессом/блокировкой UI.
- Локальные настройки в `settings.json`, лог в `app.log` (rotating).

## Как это работает (локальные источники профилей)

Приложение не выполняет сетевых запросов для получения профилей. Никнеймы и аватарки читаются с диска:

- **`<STEAM_PATH>\config\loginusers.vdf`** — основной источник никнейма.
  - Файл в формате Valve Data Format (VDF).
  - Ключи аккаунтов в нём — **SteamID64**; для сопоставления с папками `userdata` используется `AccountID = SteamID64 - 76561197960265728`.
  - Извлекается `PersonaName`, при отсутствии — fallback на `AccountName`.
- **`<STEAM_PATH>\userdata\<AccountID>\config\localconfig.vdf`** — fallback-источник никнейма.
  - Используется, если в `loginusers.vdf` нет подходящего имени.
  - Выполняется аккуратный поиск `PersonaName` (в т.ч. в секции friends / по структуре файла), при ошибке парсинга приложение не падает.
- **`<STEAM_PATH>\config\avatarcache`** — источник аватарок (best-effort).
  - Формат/именование файлов в `avatarcache` не документированы, поэтому поиск выполняется эвристически (по совпадениям в имени файла и проверке сигнатур изображений).
  - Найденные изображения кэшируются локально в `cache/avatars/<AccountID>.png`.
  - Кэш обновляется, если исходный файл в `avatarcache` новее.

**Оговорка:** загрузка аватарок из `avatarcache` работает по принципу *best-effort* и может не найти изображение для некоторых аккаунтов. В этом случае показывается встроенная заглушка-аватарка (кружок с первой буквой никнейма/AccountID, цвет детерминирован по AccountID). Если никнейм не найден в локальных файлах, отображается `AccountID`.

## Требования

- Windows 10/11
- Python 3.10+
- Установленный Steam (для работы с `userdata` и локальными файлами профилей)

## Установка и запуск (из исходников)

> Рекомендуется работать строго в виртуальном окружении, чтобы не засорять глобальный Python.

1. Перейдите в папку проекта.
2. Создайте виртуальное окружение:
   ```powershell
   python -m venv .venv
   ```
3. Активируйте venv (Windows PowerShell):
   ```powershell
   .venv\Scripts\Activate.ps1
   ```
   или (cmd):
   ```bat
   .venv\Scripts\activate.bat
   ```
4. Установите зависимости:
   ```powershell
   pip install -r requirements.txt
   ```
5. Запустите приложение:
   ```powershell
   python main.py
   ```

## Сборка EXE (PyInstaller)

Сборку выполнять внутри активированного `.venv`.

### Быстрый способ (скрипт)
```powershell
.\build.ps1
```
С очисткой предыдущих артефактов:
```powershell
.\build.ps1 -Clean
```

### Вручную
```powershell
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name "Dota2ConfigSwitcher" main.py
```

Готовый файл: `dist\Dota2ConfigSwitcher.exe`.

Если exe получается слишком большим, можно исключить неиспользуемые модули Qt и пересобрать, например:
```powershell
pyinstaller --noconfirm --clean --onefile --windowed --name "Dota2ConfigSwitcher" ^
  --exclude-module PySide6.QtWebEngineCore ^
  --exclude-module PySide6.QtWebEngineWidgets ^
  --exclude-module PySide6.QtQml ^
  --exclude-module PySide6.QtQuick ^
  main.py
```
После сборки обязательно проверьте запуск приложения.

## Настройка и использование

- **Путь к Steam**: определяется автоматически, при необходимости задаётся вручную в настройках.
- **Steam аккаунт**: выбирается в верхнем выпадающем списке (аккаунты из `userdata`).
- **Папка конфигов**: по умолчанию — рядом со скриптом/EXE. Каждый конфиг — папка, содержащая подпапку `570`.
- **Обновить профили**: кнопка в интерфейсе перечитывает `loginusers.vdf` и `avatarcache` без перезапуска приложения (полезно после входа в другой аккаунт Steam).
- **Перед применением/сохранением** рекомендуется закрыть Steam и Dota 2, иначе возможны ошибки доступа к файлам.

## Структура проекта

- `main.py` — точка входа, логирование, запуск GUI
- `settings.py` — загрузка/сохранение `settings.json`, пути к кэшу/логу
- `steam.py` — поиск Steam, перечисление аккаунтов, парсинг VDF и локальное чтение профилей/аватаров
- `configs.py` — список/валидация/копирование/удаление конфигов
- `ui/` — интерфейс (`main_window.py`, `settings_dialog.py`, виджеты, фоновые задачи)
- `build.ps1` — скрипт сборки EXE (PyInstaller)

## Хранение данных

- `settings.json` — настройки приложения
- `cache/avatars/` — локальный кэш аватарок (из `avatarcache` или сгенерированных заглушек)
- `app.log` — журнал работы приложения

Эти файлы/папки создаются рядом с приложением и добавлены в `.gitignore`. Старые поля настроек из предыдущих версий (например, `api_key`) игнорируются и удаляются при следующем сохранении.
